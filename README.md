### 🏆 Hero Projects (AI & ML)

#### [AgroScan](https://github.com/Obananob/AgroScan) (Live App)
**Stack:** TensorFlow (CNN) • Google Gemini LLM • Make.com • Vercel

A production-ready plant disease diagnosis platform deployed to the web.
* **The System:** Detects diseases using a custom CNN model trained on plant leaf datasets.
* **The Automation:** An intelligent agent fetches personalized treatment advice via **Google Gemini** and delivers it instantly to the user through the web interface.
* **Live Link:** [agroscan-amber.vercel.app](https://agroscan-amber.vercel.app)

#### [CovDetect](https://github.com/Obananob/CovDetect)
**Stack:** Deep Learning • Computer Vision • Python

A specialized Deep Learning system utilizing Convolutional Neural Networks (CNN) to classify chest X-rays.
* **Function:** Accurately distinguishes between **COVID-19 infected lungs** and **healthy lungs**.
* **Impact:** Provides rapid diagnostic support for medical image analysis using binary classification.
